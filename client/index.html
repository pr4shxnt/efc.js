Every Express app starts with the same chores: a router, a cluster, a queue, auth, a database layer. EFC does them once, so your app starts at the part that's actually yours.

Routing

The file tree is the route table.

EFC reads src/api/ when the server starts. Rename a file and its URL changes with it.

A file is a route

Export GET, POST and so on. Methods you leave out answer 405 by themselves.

Brackets are params

[id].ts becomes :id. Static paths always win, so /users/me never reaches /users/:id.

Optional and catch-all

[[id]] is optional. [...slug] takes the rest of the path as an array.

Validated on the way in

export const schema takes zod, valibot or arktype. Bad input gets a 400 before your handler runs.

Clustering

One worker per CPU core.

In production the primary process forks a worker for each core and replaces any that crash. Try crashing one.

On shutdown, SIGTERM reaches every worker, so open requests and running jobs finish first.

Background jobs

Reply first. Do the slow work after.

Each file in src/tasks/ is a job. Queue it from a handler and return 202. It runs on BullMQ or pg-boss, with retries.

src/tasks/SendWelcome.ts
import { defineTask } from 'express-file-cluster/tasks'

export default defineTask<{ to: string }>(
  { retries: 3 },
  async ({ to }) => { await mailer.send(to) },
)

// in a route handler
await enqueue('SendWelcome', { to: user.email })
res.status(202).json({ queued: true })

Data

Describe the model. Get the types.

Types come from the schema, and tables or collections are created on first use. defineModel runs on MongoDB and PostgreSQL. defineTable adds relations on PostgreSQL.

src/model/Post.ts
export const Post = defineTable('Post', {
  title:  { type: 'string', required: true },
  author: { type: 'uuid', ref: 'User' },
  tags:   { type: 'array', of: 'uuid', ref: 'Tag' },
})

const posts = await Post.findMany({
  include: { author: true, tags: true },
  take: 20,
})
// one SQL query, typed { author: User | null, tags: Tag[] }
src/model/User.ts
export const User = defineModel('User', {
  email: { type: 'string', required: true, unique: true },
  role:  { type: 'string', enum: ['user', 'admin'] },
})

type UserRecord = InferRecord<typeof User>

await User.find({ role: 'admin' })
// same call on MongoDB or PostgreSQL

Also included

The rest of the boilerplate.

Auth
JWT in a cookie or a Bearer token. requireAuth('admin') checks roles.
Cache
Redis or in memory, with cacheResponse() for GET routes.
Logging
pino, with a request ID on every line.
Scaffolder
create-efc-app writes a working app with user and admin routes.
Mailer
Gmail or any SMTP server, sent from a background job.
CLI
Route listing, migrations, seeds and a read-only database browser.
